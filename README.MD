# Multiple Linear Regression Salary Prediction

Machine learning practice project using multiple linear regression to predict salary from several input features.

## Category

Python, Machine Learning, Regression

## What This Project Shows

- Loading and cleaning a small hiring/salary dataset
- Handling multiple input features
- Training a multiple linear regression model with scikit-learn
- Making predictions from feature values
- Practicing beginner ML workflow in Jupyter Notebook

## Files

| File | Purpose |
| --- | --- |
| `hiring.csv` | Dataset used for model practice |
| `Multiple_Linear_Regression.ipynb` | Main notebook for preprocessing, training, and prediction |

## Tech Stack

`Python` `Jupyter Notebook` `Pandas` `NumPy` `scikit-learn` `Matplotlib` `Seaborn` `word2number`

## How To Run

```bash
git clone https://github.com/Priyanka571705/multiple-linear-regression-salary-prediction.git
cd multiple-linear-regression-salary-prediction
pip install pandas numpy scikit-learn matplotlib seaborn word2number jupyter
jupyter notebook Multiple_Linear_Regression.ipynb
```

Or install from the included requirements file:

```bash
pip install -r requirements.txt
jupyter notebook Multiple_Linear_Regression.ipynb
```
